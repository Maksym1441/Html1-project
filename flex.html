Флекс-елементи

Флекс-елементи (або флекс-контейнери) - гнучкий варіант розміщення елементів у контейнерах (в інших елементах)

space-between

Крайні елементи розташовуються по краях контейнера, а проміжки між елементами рівномірні.

flex-властивість

CSS властивість flex задає (еластичність або вагу) елементу. Еластичні елементи витягуються, займаючи весь відіедений для нього простір. Але елементи з різною вагою займають різну долю загадбного вільного простору(пропорційно до ваги)
