Основні селектори

Селектори Значення
* Всі елементи
Всі елементи, що мають тег <img />
.middle Всі елементи, в яких зазначено class="middle"
.selector-table th Всі елементи <th> які знаходяться в середині елементів з class="selector - table". Взагалі, пробіл між селекторами означає "в середині", пробілом можуть розділятися і інші види селекторів. Наприклад, "p d" - всі теги <b> в середині параграфів (<p>); ".bold .small" - всі елементи з классом ".small" в середині елементів з класом "bold"
p, b Кома означає "та" - спільні стилі для двох (і більше) селекторів
Частково про CSS зазначалось у попередньлму модулі про

Рекаомендований спосіб додавати стилі для всього сайту- це окремий файл, що підключається за допомогою тегу link у заголовку сторінки. Суть файлу - це послідовне застосуванн стилів для груп елементів, які потрапляють до селекторів. Можна сказати, що кожна команда CSS-файлу має структуру: 

        Знайти все, що відповідає такому селектору {
            і застосувати 
            до нього даний
            набір стилів
        }

Термін "каскадний" стверджує те, що кожна наступна команда буде поєднуватись з попередніми.
